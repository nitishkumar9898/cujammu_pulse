# Shared campus workspace redesign

The October 18 redesign interprets the [Central University of Jammu website](https://www.cujammu.ac.in/) for an authenticated campus workspace. The official site's dark blue-teal utility/navigation bands, white bilingual university masthead and circular identity informed the design. The CUJ/PULSE monogram remains a product mark; the redesign does not invent an approved university crest or copy official announcements, people, admission claims or carousel photographs.

## Implemented in the shared web and Android source

- Bilingual masthead, circular monogram, restrained teal/gold identity and accessible semantic light/dark palettes; existing Light/Dark/Auto persistence remains intact.
- Grouped desktop navigation: campus updates, learning/services, events/participation, community/support, administration and preferences. Compact screens retain a horizontally scrollable service menu with the same permitted routes.
- Welcome panel with working event/calendar shortcuts; a searchable service directory with explicit no-results recovery. Search and cards derive from the permitted route inventory, so disabled dependencies or privileged routes do not reappear through discovery.
- Calendar, campus notices, volunteer tasks and authorized readiness routes, previously reachable through cards but omitted from navigation, now appear in the matching enabled menu.
- Consistent panel geometry, button spacing, keyboard focus borders and semantic text hierarchy across existing domain screens. Route changes reset scroll and update the browser title.
- Native Sign in button connected to the existing secure native handler. An actual configured identity provider and installed-device validation are still required.

## Feedback workflow correction

Participant feedback now displays the persisted response receipt directly and supports retrieving the account's own response. It does not fetch the restricted manager summary after a successful submission. Unconfirmed submission preserves the exact response for retry. Event changes abort old requests and clear private responses; manager summaries are explicitly labelled confidential. Optional comments, identified-account disclosure, independent event scope validation and bounded response decoding are included.

## Evidence and remaining work

The redesign passed TypeScript checking, four navigation/semantic contrast tests and 68 desktop/narrow browser fixture tests, including responsive overflow, search focus, role hiding and runtime-disable checks. These fixtures establish client behavior, not real backend persistence or an installed Android application. Feedback decoder tests additionally cover malformed ratings/counts, foreign-event rows and duplicate records; its new browser scenarios need the integrated export before being counted as passed.

No claim of complete WCAG conformance, native-device acceptance or a finished platform follows from the redesign. Domain-specific workflows, private file handling, camera permissions and pending backend contracts retain their existing verification boundaries. Institutional approval of the final mark and translation, manual keyboard/screen-reader assessment, real device text scaling and representative office UAT remain necessary.
